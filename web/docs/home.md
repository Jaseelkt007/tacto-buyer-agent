# v1.9 homepage

The homepage introduces the actual v1.9 engine, the ten-case benchmark, and links to each canonical
recorded negotiation. Its figures come from `src/data/v19.json`; it never selects the latest
experimental run as the featured result. The data explorer links remain available below the cases.

Historical chapter-based stories remain available at `/story/<session>`. Those pages retain the
version label of their original saved run. See [the demo documentation](live.md) for the current
architecture, export commands, and replay controls.
